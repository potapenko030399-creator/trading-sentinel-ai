# Trading Sentinel AI

Web-прототип realtime-аналитики торгового экрана.

Возможности: screen capture через getDisplayMedia, компьютерное зрение по пикселям, поддержка/сопротивление, RSI(14), MACD(12,26,9), OCR Tesseract.js, горизонты 1/2/3/5/10 минут, ВВЕРХ/ВНИЗ/ЖДАТЬ, confidence/risk и история.

Запуск: python -m http.server 8000, затем http://localhost:8000.

Важно: это аналитический прототип, не гарантия результата. Автоматическая отправка сделок/ставок не включена.
